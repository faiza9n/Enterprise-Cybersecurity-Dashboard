# Enterprise Cybersecurity Dashboard

A modern, responsive Enterprise Cybersecurity Dashboard built using HTML, CSS, and JavaScript.

## Features

- Responsive Dashboard
- Security Analytics
- Threat Monitoring
- User Management (CRUD)
- Reports Module
- Settings Persistence
- Profile Management
- Dark Mode
- Notification Center
- Toast Notification System
- Reusable Modal System
- Profile Dropdown
- Local Storage Support

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Local Storage API
- Font Awesome
